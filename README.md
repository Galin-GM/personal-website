# Galin Mihaylov — Personal website

A responsive, single-page portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Commands

- `npm run dev` starts the development server.
- `npm run lint` runs ESLint.
- `npm run build` creates an optimized production build.
- `npm run start` serves the production build.

## Content

- Page content and sections live in `src/app/page.tsx`.
- Project details live in `src/data/projects.ts`.
- Images live in `public/`.
- The visual system and responsive styles live in `src/app/globals.css`.
